# Контейнер передачи HOP1

Клиент собирает текст и файлы в один Blob вызовом `pack({ text, files })` из `src/container.mjs`. Каждый элемент `files` содержит имя и Blob файла. Получатель вызывает `unpack(blob)` только после проверки целостности и расшифровки. Метод возвращает текст и срезы Blob в исходном порядке. Пустой контейнер и файлы нулевой длины допустимы.

| Поле | Формат |
| --- | --- |
| Версия | 4 байта ASCII `HOP1` |
| Длина манифеста | 4 байта без знака, старший байт первым |
| Манифест | JSON в UTF-8 с полями `text` и `files`. У файла есть `name` и `size` |
| Содержимое файлов | Байты файлов подряд в порядке манифеста, без выравнивания |

Локальные пределы: 1 МиБ текста в UTF-8, 6 МиБ + 20 КиБ для манифеста, 10 вложений, 255 байт UTF-8 на имя, 100 000 000 байт на вложения суммарно. Допуск манифеста учитывает экранирование JSON. Декодер отклоняет неизвестную версию, некорректный UTF-8, превышение пределов и несовпадение длины. Имена вложений являются данными для отображения. Потребитель не использует их как пути на сервере.

Обе стороны используют один модуль. Смена несовместимого формата потребует новой версии и тестов чтения уже выпущенного формата. Локальная проверка: `node --test test/container.test.mjs`.

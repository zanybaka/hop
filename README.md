# hop

Приложение доступно на [hop.pohub.ru](https://hop.pohub.ru/). Оно размещается в корне собственного поддомена. Образ собирает workflow Build image, конфигурация размещения и пробы находятся в репозитории платформы.

Docker-образ слушает `PORT` и отвечает на `/up`. Для запуска за доверенным прокси нужны `HOP_PUBLIC_ORIGIN` и `ACCESS_TRUSTED_PROXY_CIDRS`. Каталог `/state` подключают как постоянный том. На одном томе одновременно работает один экземпляр приложения.

Приложение позволяет опубликовать зашифрованный текст с файлами и открыть передачу в другом браузере по полной ссылке, QR или восьмисимвольному коду. Владелец включает код в панели «Открыть на устройстве». После публикации отправитель может закрыть страницу.

Для запуска на той же машине:

```sh
node src/server.mjs "$(mktemp -d)"
```

Открой адрес, который выведет сервер. Для обычного прогона нужен Node.js с Web Crypto и встроенным SQLite, проверено на Node.js 25.2.1. Временный каталог можно удалить после остановки сервера, если тестовые публикации больше не нужны.

Для локальной проверки внутри сайта можно запустить ту же страницу на `/hop/`. Модули, шрифты и API используют этот же префикс.

```sh
HOP_BASE_PATH=/hop node src/server.mjs "$(mktemp -d)"
```

Для сигнальных запросов за HTTPS-прокси задаётся `HOP_PUBLIC_ORIGIN` с точным адресом внешнего сайта, включая схему и порт при необходимости. [Контракт маршрутов](docs/publication-api.md)

Кнопка «Соединить по QR» запускает локальный сценарий с подтверждением. Проверено на двух независимых контекстах Chromium. В настольном WebKit на машине проверки прямая связь завершалась по таймауту. Полная ссылка открывалась в обоих браузерах.

```sh
node --test test/*.test.mjs
```

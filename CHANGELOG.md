# Изменения

## В разработке

- Добавлен версионированный контейнер передачи для текста и бинарных вложений с проверкой общего размера.
- Добавлен расчёт срока передачи по абсолютному дедлайну и подтверждённой активности.
- Добавлено клиентское шифрование контейнера и получение ключа из полной ссылки.
- HOP-004. Добавлены потоковое хранилище, резервы, проверка версии и удаление по сроку.
- HOP-005. Добавлен локальный API публикации, чтения и подтверждения получения.
- HOP-006. Добавлен браузерный сценарий публикации текста и файлов по полной ссылке и QR.
- HOP-008. Сравнены схемы короткого кода и записаны условия для реализации HOP-009.
- HOP-017. Добавлены одноразовые QR-приглашения, подтверждение соединения и прямой обмен для локальной проверки.
- HOP-011. После разрыва прямого обмена последняя переданная версия сохраняется по ссылке, которую оба браузера получили при подключении.
- HOP-011. Браузеры пары продолжают совместную запись через хранилище по исходной ссылке после разрыва.
- HOP-012. Добавлены управление режимом, приглашения для записи и проверка прав при фиксации загрузки.
- HOP-012. Приглашение на запись действует один раз. Владелец может запретить запись участнику. Сервер проверяет запрет и для уже начатой загрузки.
- HOP-009. Владелец может включить восьмисимвольный код для сохранённой передачи. Получатель вводит его на главной и открывает текст и файлы после отключения отправителя.
- HOP-013. Владелец может отключить участника сохранённой передачи. Старая общая ссылка и код перестают работать. Остальные участники с личным доступом продолжают обмен.

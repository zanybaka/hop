# 004. Открывать публикацию по короткому коду на одном сервере

Принято владельцем для локальной реализации 2026-11-14. HOP-009 дополняет [ADR 001](001-client-encryption.md).

## Контекст и решение

Новый браузер должен открыть сохранённые текст и файлы по восьми символам после отключения отправителя. Владелец выбрал один сервер и принял риск офлайн-перебора при одновременной утечке базы и закрытого ключа. Два независимых сервера ограничили бы захват одного контура ценой отдельной площадки, администрирования и зависимости от двух сервисов.

Владелец публикации включает короткий код по желанию. Браузер генерирует и скрывает код перед слепой подписью RSA, проверяет результат, затем выводит адрес и ключ небольшой зашифрованной записи. Эта запись содержит ключ и идентификатор публикации. Маршрут полной ссылки из ADR 001 продолжает работать независимо от выдачи подписей.

## Последствия

Оператор доверяет коду страницы и честной генерации ключей. При утечке закрытого ключа и связанной базы можно проверять короткие коды офлайн. Через HTTP сервис ограничивает выдачу для каждого источника и суммарно. Распределённая нагрузка может исчерпать общий лимит. Для публикации с включённым кодом путь через полную ссылку остаётся доступен при лимите, но ключ той же публикации можно получить и через подобранный код. Риск подбора короткого кода отсутствует у публикаций, для которых его не создавали.

Отдельный пароль, отзыв чтения и ручной код для приглашения в прямую пару остаются самостоятельными сценариями. Выпуск требует проверки модели угроз, реального трафика и схемы ограничения за прокси.

## Реализация и проверка

`src/short-code-crypto.mjs` и `src/short-code.mjs` реализуют клиент. `src/short-code-store.mjs` ведёт локальный индекс, ключи и лимиты. `src/server.mjs` добавляет API, `web/` показывает код и принимает ввод. Форматы и эксплуатационные условия записаны в [контракте](../docs/short-code-api.md). Хранилище создаёт два дополнительных файла при запуске и сохраняет формат существующих публикаций.

- [x] После закрытия отправителя чистый браузер открывает текст и скачивает файл по восьми символам.
- [x] Полная ссылка работает при ответе 429 на вычисление кода.
- [x] HTTP-тест проверяет владельца, неверный код, повторы, смену ключа, перезапуск и истечение.
- [ ] HOP-015 проверяет стойкость всей конструкции и доступность на целевой сети.

# Проверка интерфейса

Перед сдачей любого изменения интерфейса агент выполняет сценарии и критерии из docs/ux-checks.md. Исправление одного окна требует проверки остальных окон с тем же механизмом. Агент записывает реальные результаты и ограничения проверки. Зеленая проверка размеров не заменяет прохождение действий и просмотр снимков.

Агент не фокусирует заголовки и обычный текст при открытии окна. Он сохраняет видимый клавиатурный фокус на интерактивных элементах, проверяет Tab, Shift+Tab, Escape и возврат фокуса после закрытия. Глобально убирать outline или запрещать выделение текста нельзя.

При изменении мобильной верстки агент проверяет все кнопки, поля, диалоги, панели и сообщения, включая небольшую доступную высоту. Обязательные размеры, отступы, состояния и формат свидетельств определены в docs/ux-checks.md. Обнаруженные нарушения исправляются до передачи результата владельцу.

Правила внешнего вида фокуса применяются ко всем контролам, включая составные поля, поля только для чтения и скрытый file input с видимой подписью. Агент проверяет активный элемент через scripts/ux-audit.js при переходах мышью и клавиатурой. В текущем макете app/focus.css является единственным владельцем стилей фокуса.

Агент проверяет фактические границы подписей и пиктограмм относительно области кнопки после вычета border и padding. Одного computed padding или scrollWidth недостаточно. Повторение ошибки владельца сначала должно дать провал проверки, затем пройти после исправления. Полная мобильная приемка требует свидетельства с целевого браузера; изменение размеров настольного окна таким свидетельством не является.
